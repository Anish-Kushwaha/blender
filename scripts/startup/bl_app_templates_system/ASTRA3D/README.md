# ASTRA3D Application Template

This template provides a small ASTRA3D-branded quick-tools panel in the 3D Viewport sidebar.

## Use

1. Build or install the Blender-derived ASTRA3D Desktop application.
2. Start the application and choose the **ASTRA3D** application template from the New File template selector.
3. Open the 3D Viewport sidebar with `N` and select the **ASTRA3D** tab.
4. Use the project, create and render actions as needed.

The template does not change the scene automatically. Actions run only when selected by the user.

This is an initial workflow extension, not a full interface reskin. The graphite/orange theme, launcher, splash artwork and native application branding are tracked in the repository roadmap.
